# Sind.19-Mar API

Backend inicial de Sind.19-Mar construido con NestJS 10 y TypeScript.

## Requisitos
- Node.js 20 o superior
- npm

## Instalación
```bash
npm install
```

## Desarrollo
```bash
npm run start:dev
```

La API usa el prefijo global `/api`. Comprueba su estado en:
`GET /api/health`

## Compilar
```bash
npm run build
npm run start:prod
```

Estado: base inicial de desarrollo; todavía no es un servicio de producción.
