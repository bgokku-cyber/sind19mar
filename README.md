# Sind.19-Mar

Plataforma de transporte para La Paz, Bolivia.

## Componentes
- `sind19mar_backend_inicio/`: API central NestJS y Prisma.
- `apps/passenger/`: aplicación Android del pasajero (Expo / React Native).
- `apps/driver/`: aplicación Android del conductor (Expo / React Native).
- `apps/admin/`: panel administrativo web (React / Vite).

## Estado
Desarrollo inicial. La API tiene módulos de autenticación, viajes, conductores, administración y flotas. Las aplicaciones de pasajero y conductor incluyen acceso y flujos iniciales conectados a la API. El panel web permite revisar y aprobar conductores, vehículos y flotas. Todavía no existe despliegue de producción ni integración real de mapas o pagos.

Consulta los README de cada componente para instrucciones específicas.
